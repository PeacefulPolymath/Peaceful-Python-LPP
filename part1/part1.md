## Installing Python (It's Like Getting Your Tools Ready)

Before we can start giving commands to our Python robot, we need to install it!

### Step-by-Step Installation:

1. **Go to the Python website:** https://www.python.org
2. **Click "Downloads"** - it will automatically suggest the right version for your computer
3. **Download and run the installer**
4. **IMPORTANT:** Check the box that says "Add Python to PATH" (this makes it easier to run Python)
5. **Click Install** and wait a minute

### How to Check if Python is Installed:

Open your terminal/command prompt and type:
```bash
python --version
```

If you see something like `Python 3.12.0`, you're good to go! 🎉

## Running Python - Two Ways

You can talk to Python in two ways:

### Way 1: The Python REPL (Interactive Mode)

Think of this like having a conversation with Python. You type something, and Python replies immediately!

**How to start it:**
1. Open your terminal/command prompt
2. Type `python` and press Enter
3. You'll see `>>>` - that's Python waiting for your command!

**Try it:**
```python
>>> print("Hello, World!")
Hello, World!
>>> 2 + 2
4
>>> name = "Alex"
>>> name
'Alex'
```

To exit, type `quit()` and press Enter.

### Way 2: Writing Python Files

This is like writing a letter to Python - you write all your instructions in a file, and Python reads them all at once.

**How to do it:**
1. Create a file called `hello.py` (Python files end with `.py`)
2. Write your code in it
3. Run it with `python hello.py`

**Example `hello.py`:**
```python
print("Hello, World!")
print("I'm learning Python!")
```

**Run it:**
```bash
python hello.py
```

**Output:**
```
Hello, World!
I'm learning Python!
```
