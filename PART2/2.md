1. The Triangle Validity & Type Checker
Write a program that asks the user for 3 sides of a triangle (Side A, Side B, Side C).

     First, check if the sides can actually form a triangle. The mathematical rule is: the sum of any two sides must be strictly greater than the third side. (e.g., A + B > C AND A + C > B AND B + C > A). 
     If they cannot form a triangle, print "Invalid triangle."
     If they can form a triangle, tell the user what kind it is:
         If all 3 sides are equal: "Equilateral Triangle"
         If exactly 2 sides are equal: "Isosceles Triangle"
         If no sides are equal: "Scalene Triangle"
     Brain tease: How do you check if exactly two sides are equal without accidentally triggering it for an equilateral triangle? Think about the order of your if and elif statements.

2. The "+/-" Grading System
Write a program that asks the user for a numerical grade (0 to 100).

     Convert the input to an integer.
     Determine the base letter grade: 90+ is A, 80-89 is B, 70-79 is C, 60-69 is D, below 60 is F.
     Here is the twist: Calculate the last digit of their grade (using the modulo operator % 10).
         If the last digit is 7, 8, or 9, add a + to the letter (e.g., 88 is a B+).
         If the last digit is 0, 1, or 2, add a - to the letter (e.g., 81 is a B-).
         If the last digit is 3, 4, 5, or 6, it's just the plain letter (e.g., 85 is a B).
     Special case: 100 should be an A+ (don't make it an A- because 100 % 10 is 0!), and anything below 60 is just an F with no plus or minus.
     Print the final letter grade.
     Brain tease: Your if conditions will need to combine letter grade checks AND last digit checks using and.

3. The Leap Year Validator
Write a program that asks the user for a year.

     A year is a Leap Year if:
         It is divisible by 4. 
         EXCEPT if it is divisible by 100, then it is NOT a leap year.
         EXCEPT if it is divisible by 400, then it IS a leap year.
     Print whether the year is a Leap Year or a Common Year.
     Brain tease: You can actually solve this in one single, massive Boolean expression, or you can use nested if statements. Try doing it with a single if statement using and, or, not, and % 4 == 0 logic.

4. The Strict Club Bouncer
You are writing the logic for a club bouncer. Ask the user three questions:

    "What is your age? "
    "Are you a VIP member? (yes/no) "
    "Are you wearing sneakers? (yes/no) "

     The rules for entry are:
         You must be 21 or older.
         If you are 21 or older, you can get in IF you are a VIP, OR if you are not wearing sneakers.
         If you are under 21, you cannot get in no matter what.
     Print exactly "Welcome to the club!" or "You shall not pass!"
     Brain tease: You will need to combine integer comparisons (>= 21) with string comparisons (== 'yes'). Be careful with your and/or logic grouping using parentheses ()!
