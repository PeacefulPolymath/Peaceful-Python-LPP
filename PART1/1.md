1. The 3-Digit Digit Extractor
Write a program that asks the user for a 3-digit integer (e.g., 425). 

     Without converting the number into a string, use math operators (// and %) to isolate each digit.
     Extract the hundreds digit, the tens digit, and the units digit.
     Add those three digits together and print the result. (Example: 425 -> 4 + 2 + 5 -> prints 11).
     Brain tease: How does modulo (%) and integer division (//) help you chop up a number?

2. The "Over the Top" Time Converter
Write a program that asks the user for a massive number of minutes (e.g., 1503).

     Convert that single number of minutes into a combination of days, hours, and leftover minutes. 
     (Hint: 1 day = 1440 minutes, 1 hour = 60 minutes).
     Print the result as a single string formatted nicely. (Example output: That is 1 days, 1 hours, and 3 minutes.)
     Brain tease: You have to chain your math together. The leftover minutes from the days calculation become the input for the hours calculation.

3. The Absolute Temperature Flip
Write a program that asks the user for a temperature in Celsius (allow for negative numbers, so use float()).

     Convert it to Fahrenheit using the formula: F = (C * 9/5) + 32.
     Print the Fahrenheit temperature.
     Now, calculate the "absolute distance" between the Celsius value and the Fahrenheit value using the abs() function. 
     Print a message stating this absolute difference. (Example: If C is 0, F is 32. Absolute difference is 32. If C is -40, F is -40. Absolute difference is 0).
     Brain tease: How do you subtract a float from a float and ensure the result is always positive, no matter which one is bigger?

4. The "Censored" Word Math
Write a program that asks the user for a word, and then asks them for a "censor multiplier" number.

     Calculate the length of the word using len().
     Square that length using the ** operator.
     Add the user's censor multiplier number to that squared result.
     Create a censorship block by replicating the string '#' by that final calculated number. 
     Print the original word, then print the massive censorship block underneath it.
     Brain tease: You are combining len(), math, type conversion (if needed), and string replication all in one sequence.
